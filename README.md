# 🚀 DevQuiz Challenge (Interactive Quiz App)

Aplikasi web kuis interaktif berbasis web statis untuk menguji pengetahuan dasar pemrograman (HTML, CSS, dan JavaScript). Proyek ini dilengkapi dengan antarmuka modern bertema gelap (*Dark Mode* dengan efek *Glassmorphism*) serta memanfaatkan browser `localStorage` untuk menyimpan rekor skor tertinggi pengguna secara lokal.

## 🎯 Tujuan & Latar belakang Project
Proyek ini dikembangkan sebagai sarana edukasi dan evaluasi mandiri yang cepat serta menyenangkan bagi para pemula di bidang pemrograman web. Tanpa memerlukan *backend* atau *database* eksternal, aplikasi ini mampu berjalan langsung di peramban dengan memanfaatkan penyimpanan lokal.

---

## 🧩 Section & Fitur Utama Website
Website dirancang menggunakan format *single-page application* interaktif yang mencakup:
1. **Hero / Start Screen:** Menyambut pengguna dengan judul kuis, deskripsi singkat, dan tombol "Mulai Kuis".
2. **Main Content (Quiz Screen):** Bagian utama yang memuat nomor soal aktif, indikator skor tertinggi (`localStorage`), teks pertanyaan, serta tombol pilihan ganda.
3. **Result Screen:** Menampilkan skor akhir pencapaian pengguna serta notifikasi pencapaian rekor skor tertinggi baru (*High Score*).
4. **Contact & Footer:** Informasi penjelas sistem dan status aktif aplikasi.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5:** Kerangka dokumen web terstruktur.
* **CSS3:** Desain tata letak modern, font Inter, dan efek visual *Glassmorphism*.
* **JavaScript (ES6+):** Logika perpindahan soal, pengelolaan status skor, dan interaksi `localStorage`.
